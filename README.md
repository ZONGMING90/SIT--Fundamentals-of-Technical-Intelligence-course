# SIT--Fundamentals-of-Technical-Intelligence-course
一、课程定位：本课程《技术智能基础》（Fundamentals of Technical Intelligence）面向30³应用创新特班开设，属T1公共基础课，采用项目制教学。课程以《人工智能通识教程》（机械工业出版社，2026）为教材，按照“基础篇（第1–3章）→领域篇（第4–8章）→大模型前沿篇（第9–10章）”组织教学，每周5学时（半天）连排，共16周、80学时。
二、项目制设计：全学期贯穿一个“AI+应用创新”团队项目，设置两个里程碑（第6周基于Vibe Coding/低代码平台完成一个机器学习方法实现、第12周提交设计方案），第13–15周开展原型开发与迭代，第16周进行终期答辩并提交课题结题报告。考核形式包括：设计方案、作品、汇报（答辩）、课题结题报告。
